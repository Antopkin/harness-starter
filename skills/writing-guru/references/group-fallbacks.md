# Group fallback compounds

When compounds.md has no explicit compound for a specific pair of elements, use the generalised description at the group level.

**Coverage:** 28 group pairs (every possible combination of the 7 groups, including within a group).

## When to use the fallback

1. compounds.md has no explicit pair for the chosen elements (for example, Rk + St)
2. Identify the groups of both elements (Rk → Group 1, St → Group 7)
3. Find where the groups intersect in the table above (1×7 → Performative evaluation)
4. Use the fallback description as the basis of the text map
